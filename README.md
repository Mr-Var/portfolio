# VAR Portfolio

UI/UX, app development (Flutter) and Salesforce portfolio, built as a Flutter web app.

- Case study: MedNU (live site capture + interactive app screens)
- Figma case studies: Meridian, Courtside, Ranga
- Add exported Figma frames to `assets/figma/<project>/` and rebuild — they appear automatically

## Run

    flutter run -d chrome

## Build

    flutter build web --release

Personalise: edit the constants at the top of `lib/sections/portfolio_page.dart`.

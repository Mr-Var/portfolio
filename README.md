# VAR Portfolio

UI/UX, app development and Salesforce portfolio.

**The live site is the React + Vite app in [`site/`](site/README.md).** Vercel builds it from the root `vercel.json`.

- Case study: MedNU (live site capture + interactive app screens)
- Figma case studies: Meridian, Courtside, Ranga
- Add exported Figma frames to `site/src/assets/figma/<project>/` and rebuild — they appear automatically

## Run the website

    cd site
    npm install
    npm run dev

Personalise: edit the constants at the top of `site/src/App.jsx`.

## Original Flutter version

The original Flutter web app is still in `lib/` for reference.

    flutter run -d chrome
